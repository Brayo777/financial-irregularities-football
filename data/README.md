# Data

This folder contains the dataset used in the dissertation analysis.

The dataset is an unbalanced panel of European football clubs observed across multiple seasons. Each observation represents a club–season and includes financial indicators and sporting performance metrics.

Key variables include:

- Financial Irregularity indicator
- League Standing
- Net Profit Margin
- Firm Size
- Leverage
- Growth
- Return on Equity
- Goal Ratio

The dataset is used as the input for all econometric analysis scripts contained in the `code/` directory.

No data preprocessing is required before running the analysis pipeline.
