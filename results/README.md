# Results

This folder contains all outputs generated by the analysis pipeline.

The contents of this folder are created automatically when the full pipeline is executed.

To reproduce the results, run:

python code/run_all.py

Outputs include:

tables/  
Regression tables, descriptive statistics, correlation matrices, and model diagnostics.

figures/  
Plots and diagnostic visualisations produced during the analysis.

These files are generated automatically and may be overwritten each time the pipeline is executed.
